## 🌟 Choose a Design Direction (`designs.html`)

Open **`designs.html`** to view the interactive executive presentation and compare the three visual design directions side-by-side. Each design is a **complete, responsive five-page website** (Home, About Us, Services, Our Work & Projects, Contact & Free Quote):

## 💻 Tech Stack & Tailwind Build

- **Framework**: Semantic HTML5, Tailwind CSS v3, Vanilla JavaScript ES6+.
- **Typography**: Google Fonts (`DM Sans`, `Manrope`, `Playfair Display`).
- **Icons**: Crisp inline SVG helpers (100% offline and CDN resilient) + optional Lucide icons.
- **Responsive**: Fully responsive across mobile, tablet, laptop, and 4K displays.

### Building Tailwind CSS Locally:

```sh
cd lovecontst
npm.cmd run build:css
```

To watch for file changes during development:
```sh
npm.cmd run watch:css
```
